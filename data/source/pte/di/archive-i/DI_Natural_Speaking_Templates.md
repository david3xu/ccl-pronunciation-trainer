# PTE Describe Image - Natural Speaking Templates

> **设计原则：** 自然口语，多样化句式，只填名词，~80词/35秒
> **Pause "/" 标记呼吸点**
> **优化特点:** ✅ 每个填空前有1.5-3秒思考时间 ✅ 只用简单词汇 ✅ 灵活表达

---

## Template 1: 极值模板 - 单分类/多分类 (Unified)

**适用于:** bar/line/pie chart, table, map, grouped charts, multi-line graphs

**使用说明:**
- 单分类图表: 省略 "from [group]" 部分
- 多分类图表: 使用完整模板

```
This picture shows information about [title].

Looking at the image, / we can see from [group 1] / the highest number appears in [item], /
which is close to [value].

On the other hand, / the lowest number can be found in [item], /
with a value of only [value].

We can also notice that / the number in [item] is quite high as well, which is from [group 2] /
and the value is about [value].

In addition, / [item] and [item] /
are also in this picture.

To sum up, / this picture tells us about [title].
```

## Template 3: 流程模板 (Optimized)

**适用于:** flow chart, cycle diagram, process

```
This picture shows the process of [title].

Looking at the image, / the first step is [step 1], /
which appears at [location].

As the process continues, / [step 2] takes place, /
which then leads to [step 3].

After that, / [step 4] happens at [location] /
in the picture.

Finally, / the process ends with [final step].

To sum up, / this picture tells us about [title].
```

**循环图替换结尾:**
```
Finally, / the cycle returns to [step 1].
```

**对比图额外句子:**
```
On the other hand, / [item 2] has a different [aspect] /
compared to [item 1].
```

## Template 4: 图片模板 (Optimized)

**适用于:** photos, illustrations, diagrams, floor plans, maps

```
This picture shows information about [topic].

Looking at the image, / we can see [element] on the top, /
which connects to [element].

On the left side, / [element] can be found /
close to [element].

On the right side, / [element] also appears /
in the picture.

At the bottom, / [element] can also be seen /
in the picture.

To sum up, / this picture tells us about [topic].
```

## Template 5: 多分类对比模板 - 无数值 (Optimized)

**适用于:** comparison charts without numbers, category diagrams, trade/flow diagrams

```
This picture shows information about [title].

If we look at [category 1], / the main items include /
[item] and [item].

On the other hand, / [category 2] includes /
[item] and [item].

If we move to [category 3], / the main items are /
[item] and [item].

We can also see / [other categories] /
in this picture.

To sum up, / this picture tells us about [title].
```

## RL Template: Retell Lecture (Optimized)

**适用于:** Retell Lecture - 8 content slots, ~85 words

```
The lecture talks about [topic] / and its importance.

The speaker mentions that / [content 1] and [content 2] /
are related to [topic].

According to the speaker, / [content 3] and [content 4] /
are important in this context.

The lecture also discusses / how [content 5] and [content 6] /
play a role.

Furthermore, / [content 7] is mentioned /
as a key point.

Finally, / the speaker talks about [content 8] /
and its connection to [topic].

In conclusion, / the lecture is mainly about [topic].
```

## SGD Template: Summarize Group Discussion (Optimized)

**适用于:** Summarize Group Discussion - 8 terms per speaker × 3 speakers, ~205 words

```
The discussion is about [topic].

--- SPEAKER 1 ---
The first speaker talks about [term 1] / and its importance.
The speaker mentions that / [term 2] and [term 3] / are related to [term 1].
According to this speaker, / [term 4] and [term 5] / are important in this context.
However, / [term 6] is discussed / as a challenge.
The speaker concludes that / [term 7] and [term 8] / are the key points.

--- SPEAKER 2 ---
Moving to the second speaker, / who discusses [term 9].
This speaker mentions that / [term 10] and [term 11] / play a role.
The speaker also discusses / [term 12] and [term 13] / in this context.
On the other hand, / [term 14] is mentioned / as a challenge.
The speaker suggests that / [term 15] and [term 16] / could be solutions.

--- SPEAKER 3 ---
Similarly, / the third speaker talks about [term 17].
According to this speaker, / [term 18] and [term 19] / are significant.
The speaker also mentions / [term 20] and [term 21] / as important aspects.
At the same time, / [term 22] needs / to be considered.
The speaker believes that / [term 23] and [term 24] / are the way forward.

--- CLOSING ---
All speakers agree that / [common 1] and [common 2] / are important.
In conclusion, / the discussion is mainly about [topic].
```
