## Template 1: Charts with Data (Line/Bar/Pie/Table)

**Use for:** Graphs, charts, tables with numerical data

**UNIVERSAL VERSION (Works with limited data, fills 30-40 seconds):**
```
The image provided is a [image type] which presents information about [title]. |

Looking at the main parts this [title] includes [item 1] [item 2] [item 3] and [item 4]. |

The data shows [categories or x-axis] with values in [units or y-axis or percentages]. |

It's clear that [item 1] is around [value 1] which is one of the key data points here. |

On the other hand [item 2] shows around [value 2] in this [title]. |

We can also see [item 3] at around [value 3] and [item 4] at around [value 4] in the data. |

These values give us a good view of how [title] changes across different points. |

To sum up this image displays data on [title] in a simple form. |
```

**Note:** For pie charts, use "categories/items with values in percentages". For bar/line graphs, use "x-axis with values in y-axis".

**Each chunk:** 10-15 words for natural flow
**Total speaking time:** ~35-40 seconds
**Key term repetition:** [title] × 4 times, values and items × 1-2 times each

```
At the bottom we have [element 4] and [element 5] in the process. |

We can also see [element 6] connects to [element 1] in this [title]. |

All these parts work together to show how [title] functions as a system. |

In summary this [image type] gives us information about [title]. |
```

**For cycles (replace last sentence):**
```
Once finished everything loops back to the beginning and the cycle continues. |
```

**If only 2-3 elements available:** Repeat elements in placeholders (e.g., [element 1] [element 2] [element 1] [element 2])

**Each chunk:** 10-15 words for natural flow
**Total speaking time:** ~35-40 seconds
**Key term repetition:** [title] × 4 times, each element × 2 times

## Key Principles

1. **Each breath chunk = 10-15 words** for natural fluency
2. **Fill only exact words from image** (no interpretation, no additions)
3. **Natural conversational phrases** - how people actually speak
4. **Flexible structure:**
   - Images with many details → use full template
   - Images with few details → use CORE version for better flow
5. **Longer chunks = better fluency** - avoid choppy short pauses
6. **Memorize template + read from image = zero thinking time**
