# DI Templates - Simple & Fluent

## Template A: Line/Bar/Pie Charts

```
This [LINE graph / BAR chart / PIE chart] clearly shows some DATA about [topic].

At the TOP of the chart we can see [item 1] with the HIGHEST number of around [value].

Then right below that we have [item 2] showing around [value] which is the SECOND highest number here.

Moving down to the BOTTOM we can see that [item 3] has the LOWEST number at around [value].

We can also see some other items like [item 4] and [item 5] in this chart as well.

So overall this chart gives us some useful DATA about [topic].
```

---

## Template B: Comparing Groups

```
This chart clearly shows some DATA about [topic].

First of all looking at [group 1] we can see [item 1] is the HIGHEST at around [value] |
while on the other hand [item 2] is the LOWEST at around [value].

Now if we look at [group 2] we can see [item 3] is the HIGHEST at around [value] |
and then [item 4] comes next at around [value].

We also have some other items like [item 5] and [item 6] in the DATA here.

So overall this chart helps us compare these two groups together.
```

---

## Template C: Process/Flow

```
This chart clearly shows us how the process of [topic] works.

First of all it starts with [step 1] as the beginning.

Then after that [step 2] comes next in the process.

After that we have [step 3] taking place here.

This then leads to [step 4] in the next stage.

And finally [step 5] is the last step in this process.
```

**For cycles:**
```
And finally it goes back to step one and starts again.
```
