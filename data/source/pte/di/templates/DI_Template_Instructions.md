# DI Template Instructions

## How to Use Templates in Real Test

### 1. No Thinking Required
- Memorize the template phrases
- Just read template + fill in exact words from image
- Don't interpret, don't paraphrase, don't add anything

### 2. Fill Only Direct Words
- Copy exact terms from image: titles, labels, numbers, legends
- Example: Image shows "Water Flow" → say "water flow"
- Don't add connecting words between filled terms

### 3. Long Flowing Chunks
- Each breath should cover substantial content
- Longer phrases = fewer pauses = better fluency = less hesitation
- Template phrases provide the flow

### 4. Pause Points (|)
- Mark where to breathe naturally
- Usually after complete thoughts
- Keep chunks long enough to sound confident

### 5. Test with Real Images
- Practice with actual DI images
- Find where you hesitate
- Improve template if chunks feel too short or awkward
- Ensure all filled words exist directly in the image

## Goal
**Speak fluently with zero thinking time by using memorized template + direct reading from image**
