## Describe Image 模板

### 使用方法
1. 若图中内容词太多，只需要填满模板即可；若图中内容词太少，可以重复填入模板；
2. 【极值模板】和【流程模板】所填信息尽量符合"句意逻辑"，【图片模板】尽量把图中位置挨在一起的信息填入同一句话里；
3. 答题时不要呈现机械僵化的背诵感，朗读效果应该尽量贴合我们平时自然聊天说话的方式，有自然的语速、停顿、语调的变化等。

## 极值模板（适用于line/bar/pie/table/map） - 单分类

```
This bar/line/pie/table chart/map shows information about 标题.

Firstly, the highest number can be found in 最大项目, which is around 最大数值.

Secondly, the second-highest number is located in 第二大项目, which is about 第二大数值.

Thirdly, the lowest figure is for 最小项目, and the number is around 最小数值.

Furthermore, 其他项目1 and 其他项目2 also carry important weight in this graph.

In summary, this chart uses real data to describe 标题.
```

## 流程模板（适用于所有流程图）

**注意：**
- 如果超过四步，可以用"第一步 and 第二步"填入"第一步"的空位，以此类推；
- 如果不足四步，可以删除中间步骤模板句

```
This flow chart shows information about 标题.

According to the picture, we can see that

Firstly, the process starts from the first stage, which is called 第一步

Secondly, it goes to the second stage, which is about 第二步

Thirdly, it comes to the third stage, which is called 第三步

Furthermore, the process comes to the ending point, which is about 最后一步.

In summary, the process shows details about 标题.
```

**或者【循环图】的结尾句可以换成：**
```
In the end, the process will start again from the very beginning.
```

## 图片模板（适用于所有图片题）

**注意：**
- 有文字的图片，把图片中的文字依次填入模板；
- 文字不够填或不含文字的图片，把图片中能总结出的"名词概念"或"动词"依次填入模板，不必在意语法正误。

```
This picture shows information about 标题.

If you look at 图片1/方位1,
the most obvious information given here is ___.

Next to it,
we can see ___ and ___, and these elements are also quite important.

If you look at 图片2/方位2,
___ and ___ are also shown in this part, giving a better understanding about this picture.

Furthermore,
we can also see ___ and ___ in this picture as well.

In summary, this picture uses different elements to describe 标题.
```

# Retell Lecture 模板

### 使用方法
1. 所填要点都出自原文，不必提到原文中没有的信息；
2. 尽量记录"词组"，词组比零碎单词更有内容价值；
3. 如果记录了完整句子，可以改述原句后填入"要点"位置，不用考虑语法对错；
4. 尽量考虑要点之间的逻辑关联性，前后空所填要点最好是在原文中挨在一起的信息；
5. 每句内容句含有 2 个空：
   a. 若要点太多，可以用 A and B 的方式把两个要点合并填入一个空里；
   b. 若要点太少，可以重复填。

### 模板

```
This lecture is mainly talking about 主题词.

Firstly, the lecture begins by giving an introduction about 要点 and 要点.

Secondly, 要点 and 要点 are mentioned by the speaker, which is tied to the topic.

Thirdly, the speaker provides a lot of details about 要点 and 要点.

Furthermore, the lecture argues the point of 要点 and 要点 to support the main idea.

In summary, the lecture covers the topic of 主题词.
```

# Summarize Group Discussion 模板

### 使用方法
1. 主题句：明确整篇讨论的主题，填入"主题"空里；
2. 分论点句：填入下一段的任意要点；
3. 内容句：
   a. 发言者和发言内容无需严格对应，但一句内容句中的要点需来自同一段发言
   b. 每句内容句含有 4 个空：
      i. 若听到的要点多于空格数，则一空内填两个要点；
      ii. 若听到的要点少于空格数，则"要点 and 要点"的结构里填一个要点；
   c. 当发言段数与模板句数不匹配时：
      i. 若发言段数少于模板句数，则舍弃剩余模板句；
      ii. 若发言段数多于模板句数，则重复使用任意模板句；
4. 要点套入模板时，不用考虑语法对错；
5. 答题时避免机械僵化的背诵感，口语表现应贴合平时聊天时的说话方式，有自然的语速、停顿、语调的变化等。

### 模板

```
The conversation is about three speakers discussing 主题词.                    【主题句】

Firstly, one key aspect discussed is 要点.                                    【分论点句 I】
• Speaker 1 talks about 要点 and 要点, which is connected to 要点 and 要点.    【内容句 1】
• Then, Speaker 2 agrees/disagrees, and says 要点 and 要点 is important to 要点 and 要点.  【内容句 2】
• And then, Speaker 3 mentions 要点 and 要点, and it contributes to 要点 and 要点.        【内容句 3】

Following that, another important idea is about 要点.                          【分论点句 II】
• Speaker 1 talks about 要点 and 要点, which is tied to 要点 and 要点.         【内容句 4】
• Also, Speaker 2 agrees/disagrees, and says 要点 and 要点 is crucial for 要点 and 要点.  【内容句 5】
• And also, Speaker 3 mentions 要点 and 要点, and it leads to 要点 and 要点.             【内容句 6】

Moreover, they also discuss 要点.                                              【分论点句 III】
• Speaker 1 talks about 要点 and 要点, which is related to 要点 and 要点.      【内容句 7】
• Later, Speaker 2 agrees/disagrees, and says 要点 and 要点 is essential to 要点 and 要点. 【内容句 8】
• And later, Speaker 3 also mentions 要点 and 要点, and it refers to 要点 and 要点.       【内容句 9】
```

# Respond to a Situation 模板

### 使用方法
1. 根据对象、情景、诉求选择对应模板句；
2. 正文部分：在准确表达原意的情况下，可进行同义替换原文词汇或变化原文句型，尽可能改述题干，且一定要使用第一人称进行讲述；
3. 正文和结尾部分：可适当拓展细节信息
   - 如：题干说 before weekend，答案可细化为 by the end of this Friday；
4. 答题时避免机械僵化的背诵感，口语表现应贴合平时聊天时的说话方式，有自然的语速、停顿、语调的变化等。

### 模板

**开头 - 问候语（建议 1-2 句话）**

根据对象和情景选择对应模板句：

| 情景 | 模板句 |
|------|--------|
| 【对象名称已知】 | Hi / Excuse me, 人称. |
| 【对象名称未知】 | Hi, excuse me! / Hi, how are you? |
| 【电话留言】 | Hi, this is 自己的名字. |

若为正式语境，可以选择说：
- Hope I'm not interrupting you!
- May I take a moment of your time?

**正文 - 情景阐述（建议 2-3 句话）**

改述题干，并适当添加细节
注意使用第一人称改述

**结尾 - 说明诉求（建议 1-2 句话）**

| 诉求类型 | 非正式语境 [IF] | 正式语境 [F] |
|----------|-----------------|--------------|
| 【提建议】 | I think it will be a good idea if you/we can… | I suggest you/we consider… |
| 【寻求建议】 | What do you think about…? | Could you provide some advice on…? (I'd really appreciate your suggestions.) |
| 【寻求帮助】 | Would you help me out with…? (Thanks so much!) | Would it be possible for you/me to…? (I'd really appreciate your help.) |
| 【道歉】 | Sorry about that! | I sincerely apologize for …! |
| 【致谢】 | Thank you for…! | I am deeply grateful for your …! |

*[IF]代表非正式语境，[F]代表正式语境

# Summarize Spoken Text 套句模板

### 使用方法
1. 抓取：尽量从原文中听出"主题词"及各方面关键信息；
2. 填写：尽可能按照原文逻辑填入关键句；
   - 针对模板第四句，可根据原文逻辑对应选择 In addition（并列/顺承关系）或 However（转折/对比关系）；
3. 语法："主题词"需为名词性结构；确保关键句语法正确，简单句式即可，无需复杂；
4. 字数：完成后请务必通读检查，确保最终字数满足 50-70 字的要求。

### 套句模板

> 为方便浏览，模板分为多行。但实际考试中，SST 不能分行，必须写成一个自然段。

```
The lecture elaborates on the topic of 主题词.
Firstly, the speaker mentioned (that) 关键句.
Secondly, the lecturer showed (that) 关键句.
In addition / However, the speaker emphasized (that) 关键句.
Moreover, the talk highlighted (that) 关键句.
```

**纯模板字数：28 words**

### 简化版（适合能抓取更多信息的同学）

```
The lecture elaborates on the topic of 主题词.
Firstly, 关键句.
Secondly, 关键句.
In addition / However, 关键句.
Moreover, 关键句.
```

**纯模板字数：12 words**

# Summarize Written Text 小作文模板

### 使用方法

阅读原文后，选出最关键的几句话，同义替换改写后，用连词连接成句。
句子数量不限，但不能超字数，多多益善，尽量全面。

### 模板

```
______, 连词 _____, 连词______, 连词______, 连词______.
```

### 注意

**选择什么样的句子？**
- 各个方面具有总结性的句子；
- 重点关注每段的首、尾句，以及一些并列、转折、因果逻辑词所在的句子。

**选择什么样的连词？**

选择符合原文逻辑关系的连词：

| 并列 | 转折 | 让步 | 对比 | 原因 | 结果 | 伴随 | 解释 |
|------|------|------|------|------|------|------|------|
| and | but | although | whereas | because | so | while | which means |

**填入模板时：**
- 摘抄的句子需进行同义替换；
- 改写后的句子以连词和逗号相连，最终以句号结尾（只能出现一个句号，在最末尾处）；
- 确保最终答案字数满足 5-75 字的要求。

# Write Essay 大作文【151 套词模板】

### 使用方法
1. 审题：根据题目类型，确认观点、以及各段落论点内容；
2. 填写：全面准确理解题干，确认自己的观点切合题目，并填写使论证逻辑正确合理的关键词；
   - [理由/优点/缺点/解决/特点] 可用英文词：reason/consideration (理由类), advantage/benefit (优点类), disadvantage/problem (缺点类), solution/recommendation (解决类), feature (特点类)
   - [例子来源] 若题干无特殊要求，可填具体机构名称，如 the Australian government, Microsoft；若题干要求 "use your own experience to explain"，改为：
     - 例子来源 1：according to my own experience/story
     - 例子来源 2：to take myself as an example
   - [话题相关对象] 可填对象：特定人群、组织/机构、国家/地区
   - [资源/时间/努力/精力/金钱（等）] 可用英文词：resources (资源), time (时间), efforts/commitment (努力), energy/dedication (精力), money/funding (金钱)
3. 语法：需在 [观点句] [改写观点句] 处填写完整句子，简单句式即可，无需复杂；其他所填内容均需为名词性结构；确保所填内容语法正确；
4. 字数：完成后请务必通读检查，确保最终字数满足 200-300 字的要求。

### 模板

**第一段**
```
There is no doubt that the debate over [关键词] has drawn attention from the general public in the modern world.

Personally speaking, I firmly believe that [观点句], which will be supported by the following discussion.
```

**第二段**
```
First and foremost, when it comes to [关键词], the most important [理由/优点/特点] is that [关键词] can potentially bring about [关键词].

To be more specific, [关键词] will generate [关键词], which will consequently result in [关键词].

For instance, according to the annual report of [例子来源1], at least 80% of [话题相关对象] have experienced [关键词] because of [关键词].
```

**第三段**
```
On the other hand, in terms of [关键词], another/one significant [理由/缺点/解决/特点] is that [关键词] can possibly cause [关键词].

To illustrate, [关键词] can give rise to [关键词], thereby leading to [关键词].

To take a recent study from [例子来源2] as an example, more than 60% of [话题相关对象] have faced [关键词] as a result of [关键词].
```

**第四段**
```
With all the points above, it can be concluded that [改写观点句], because [关键词] and [关键词] both play a vital role in this case.

Therefore, it is of utmost importance that [话题相关对象] should devote [资源/时间/努力/精力/金钱（等）] to this.
```

**模板字数：151 词**

# Write Essay 大作文套句模板

### 使用方法
1. 审题：根据题目类型，确认观点、以及各段落论点内容；
2. 填写：全面准确理解题干，确认自己的观点切合题目，并填写正确论证逻辑的句子；
   - [理由/优点/缺点/解决/特点] 可用英文词：reason/consideration (理由类), advantage/benefit (优点类), disadvantage/problem (缺点类), solution/recommendation (解决类), feature (特点类)；
   - [例子来源] 若题干无特殊要求，可填"来自某机构的报告/研究/数据"；若题干要求"use your own experience to explain"，可填 my own experience/story (例子来源 1), myself (例子来源 2)；
3. 语法：需在[理由/优点/缺点/特点] [例子来源] 处填写名词性结构，其他所填内容均需为完整句子；确保所填句子语法正确，简单句式即可，无需复杂；
4. 字数：完成后请务必通读检查，确保最终字数满足 200-300 字的要求。

### 模板

**第一段**
```
There is no doubt that [改写题目中所描述的主题/现象].

Personally speaking, I firmly believe that [观点句], which will be supported by the following discussion.
```

**第二段**
```
First and foremost, the most important [理由/优点/特点] is that [第1个论点].

To be more specific, [具体阐述第1个论点].

For instance, according to [例子来源1], [支持第1个论点的例子].
```

**第三段**
```
On the other hand, another/one significant [理由/缺点/解决/特点] is that [第2个论点].

To illustrate, [具体阐述第2个论点].

To take [例子来源2] as an example, [支持第2个论点的例子].
```

**第四段**
```
With all the points above, it can be concluded that [改写观点句], because [改写第1个论点] and [改写第2个论点].

Therefore, it is of utmost importance that [提出建议].
```

**模板字数：69 词**
